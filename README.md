# Flexbox-practice
Flexbox layout practice based on a Figma design

This project is a Flexbox practice layout built to explore and understand how different Flexbox properties affect layout behavior.
Each container demonstrates a specific Flexbox configuration using combinations of:

* flex-direction

* justify-content

* align-items

* align-self

* spacing with gap, margin, and padding

The goal is hands-on learning through visual comparison.
